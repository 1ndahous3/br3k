### SourceKind

[Source](../../../lib/src/pe/export_map.rs#L9)

Provenance of an export table in the symbol index.

- `Unknown`: Source provenance was not recorded.
- `Disk`: Exports were parsed from file-layout bytes.
- `Mapped`: Exports were parsed from mapped process bytes.

### SourcePolicy

[Source](../../../lib/src/vm/py_pe/types.rs#L5)

Export-source selection policy for a process analysis view.

- `Auto`: Try disk exports first, falling back to mapped exports on acquisition or parsing failure.
- `Disk`: Require file-backed exports; record failures without using mapped fallback.
- `Mapped`: Require exports parsed from captured target memory.
