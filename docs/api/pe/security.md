### DirectoryInfo

[Source](../../../lib/src/vm/py_pe/diagnostics.rs#L505)

Certificate-table location. Its address is a file offset, unlike other PE directories.

Presence does not validate an Authenticode signature; certificate data is not normally part of the mapped image.
