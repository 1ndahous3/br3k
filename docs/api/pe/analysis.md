### FindingKind

Classification of a process-memory scan finding.

### HiddenModuleReasonKind

[Source](../../../lib/src/vm/py_pe/types.rs#L17)

Evidence contributing to a hidden-module candidate's ranking. No single reason proves malicious code.

- `OutsidePebModuleList`: Candidate allocation is outside the loader's module inventory.
- `DetachedImageRegion`: Image-backed memory is not associated with a listed loader module.
- `PrivateExecutableRegion`: Allocation contains private executable memory.
- `MappedExecutableRegion`: Allocation contains executable mapped-section memory.
- `WritableExecutableProtection`: Memory protection permits both writing and execution.
- `MixedExecutableAndNonExecutableRegions`: Allocation combines executable and non-executable regions.
- `ManualSelection`: Range was explicitly selected by the caller.
- `HeaderArtifact`: PE-shaped header or section-table evidence was found.

### ImageAnomalyKind

[Source](../../../lib/src/pe/diagnostics/anomalies.rs#L19)

PE header, section, or directory condition reported by structural inspection.

- `UnknownMachine`: COFF machine value is not recognized by the inspector.
- `NonExecutableImage`: COFF characteristics do not mark an executable image.
- `SectionZeroSize`: Section has no effective virtual or raw extent.
- `SectionVirtualRangeOverflow`: Section RVA and size overflow their numeric range.
- `SectionVirtualOutsideImage`: Section virtual extent exceeds SizeOfImage.
- `SectionVirtualOverlap`: Virtual section ranges overlap.
- `SectionRawRangeOverflow`: Section file offset and size overflow their numeric range.
- `SectionRawOutOfBounds`: Section raw bytes extend beyond the file buffer.
- `SectionRawBeforeHeaders`: Section raw data begins inside the header area.
- `SectionRawOverlap`: Raw file ranges of sections overlap.
- `EntryPointOutsideSections`: Entry-point RVA is outside the section ranges.
- `ExecutableWritableSection`: Section characteristics permit both execution and writing.
- `MissingImportDirectory`: Image does not declare a normal import directory.
- `DataDirectoryRangeOverflow`: Directory address and size overflow their numeric range.
- `DataDirectoryOutsideImage`: Directory extent exceeds the virtual image.
- `DataDirectoryOutsideSections`: Directory range is not contained by the expected image sections.
- `InvalidBoundImportDirectory`: Bound-import metadata could not be parsed or validated.

### ImageAnomalySeverity

[Source](../../../lib/src/pe/diagnostics/anomalies.rs#L7)

Review priority of a PE metadata anomaly, not a malware classification.

- `Info`: Informational structural observation.
- `Warning`: Potential inconsistency or limitation.
- `Suspicious`: Pattern deserving closer inspection, with possible benign explanations.

### ThreadStartKind

[Source](../../../lib/src/vm/py_pe/types.rs#L57)

Classification of the memory containing a thread's recorded start address.

- `LoadedModule`: Address belongs to a listed loaded module.
- `PrivateExecutableRegion`: Address belongs to private executable memory.
- `MappedExecutableRegion`: Address belongs to executable mapped-section memory.
- `DetachedImageRegion`: Address belongs to image-backed memory outside listed modules.
- `OrphanExecutableRegion`: Address belongs to other executable memory without module ownership.
- `NonExecutableRegion`: Address belongs to a region without executable protection.
- `Unmapped`: No region in the captured map contains the address.
- `Unknown`: Start address or classification evidence is unavailable.
