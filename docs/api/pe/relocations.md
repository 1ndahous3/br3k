### Kind

[Source](../../../lib/src/pe/relocations.rs#L43)

Decoded base-relocation type. Decoding a type does not imply that rebasing supports every architecture-specific form.

- `Absolute`: Padding entry; no relocation is applied.
- `High`: High 16-bit portion of a relocation.
- `Low`: Low 16-bit portion of a relocation.
- `HighLow`: 32-bit absolute-address relocation.
- `HighAdj`: Paired high-part relocation with a signed adjustment.
- `Dir64`: 64-bit absolute-address relocation.
- `Unknown`: Raw relocation type is not represented by a recognized variant.
