### BoundStatus

[Source](../../../lib/src/pe/bound_imports/validation.rs#L20)

Result of matching bound-import metadata to available dependency evidence.

- `TimestampMatch`: Recorded and dependency timestamps agree.
- `TimestampMismatch`: Recorded and dependency timestamps differ.
- `DependencyMissing`: Dependency export source is unavailable.
- `DependencyAmbiguous`: Multiple dependency sources prevent an unambiguous match.
- `TimestampUnavailable`: The dependency source has no usable timestamp.
- `MissingBoundDescriptor`: Import metadata expects a bound descriptor that was not found.
- `InvalidTimestamp`: Recorded binding timestamp is not valid for the descriptor form.
- `InvalidForwarder`: Forwarder metadata failed validation.

### DelayRecoveryStatus

[Source](../../../lib/src/pe/delay_imports/recovery.rs#L9)

Outcome and source of delay-import recovery analysis.

- `Declared`: Usable delay imports were found through the declared directory.
- `Discovered`: A candidate directory was found by bounded scanning.
- `NotFound`: No usable delay-import candidate was found.
- `Ambiguous`: Multiple candidates remain; no unique directory was selected.
- `ScanLimit`: Scanning reached a configured safety bound.
- `FromSource`: Recovery evidence came from a validated reference image.
- `InvalidImage`: Image structure prevented reliable delay-import recovery.

### EvidenceKind

[Source](../../../lib/src/pe/imports/types.rs#L90)

Origin of evidence supporting a recovered import.

- `IatDirectory`: Slot came from the declared IAT directory.
- `IatRange`: Slot came from an explicitly selected or scanned IAT range.
- `CodeReference`: A recognized code pattern refers to an IAT slot.
- `DirectBranch`: A recognized direct API branch supplied import evidence.
- `ThunkTrace`: Following supported thunk patterns led to an export.
- `ManualSlot`: Caller explicitly supplied this import slot.
- `ImportDeclaration`: Surviving import declaration supplied the name or ordinal.
- `ImportModuleContext`: Neighboring import-module context helped select the target.

### IssueKind

[Source](../../../lib/src/pe/imports/types.rs#L334)

Structural or heuristic issue found in an editable import model.

- `InvalidFunction`: Function is marked invalid or retains an unresolved target.
- `AdjacentDifferentModule`: Adjacent slots are assigned to different modules.
- `DuplicateThunkRvaAcrossModules`: Multiple modules claim the same IAT slot RVA.
- `DuplicateImportTargetInModule`: A module contains repeated references to the same import target.
- `EmptyModuleRange`: Module declares an empty IAT range.
- `FunctionAdjacentToRangeGap`: Function lies next to an unpopulated part of a module's IAT range.
- `ImportModuleMissingExportTable`: No export table is available to validate the import module.
- `ImportTargetMissingFromExports`: Declared import target could not be found in the available export table.
- `ModuleWithoutValidFunctions`: Module has no functions marked valid.
- `OrdinalOnlyImportHasNamedExport`: Ordinal import resolves to an export that also has a name.
- `OverlappingModuleRange`: Declared IAT spans of different modules overlap.
- `RepeatedImportTargetRun`: Consecutive slots repeat the same target.
- `SparseModuleRange`: Declared module span has gaps between populated slots.
- `SingletonValidFunction`: Only one valid function supports a module range.
- `ThunkMisalignedInModuleRange`: IAT slot is misaligned for the model's target pointer width.
- `ThunkOutsideModuleRange`: Function's slot RVA lies outside its module's declared span.

### IssueSeverity

[Source](../../../lib/src/pe/imports/types.rs#L399)

Impact of an import-model finding. Heuristic findings do not prove malicious or incorrect code.

- `Error`: Structural or unresolved-target problem requiring attention before a complete build.
- `Warning`: Inconsistency that should be reviewed.
- `Suspect`: Heuristic pattern that may warrant closer inspection.

### LookupKind

[Source](../../../lib/src/pe/imports/directory.rs#L20)

Interpretation of the thunk table used to parse one import descriptor.

- `OriginalFirstThunk`: Names and ordinals were read from OriginalFirstThunk.
- `FirstThunk`: Names and ordinals were read from FirstThunk because no separate lookup table was available.
- `BoundAddresses`: FirstThunk contains file binding addresses rather than import-name entries.
- `ResolvedAddresses`: FirstThunk contains addresses resolved in a mapped image.

### ResolutionKind

[Source](../../../lib/src/pe/imports/types.rs#L118)

How an observed target was associated with an import.

- `Exact`: Observed address matched an export exactly.
- `Nearest`: Observed address was associated with a nearby preceding export.
- `Forwarded`: Export forwarding was used to identify the target.
- `ApiSet`: API-set contract resolution was used to identify the target.
- `Unresolved`: No usable export identity was established.

### WriteMode

[Source](../../../lib/src/pe/imports/types.rs#L56)

Placement policy for rebuilt imports.

- `PreserveIatSlots`: Retain existing IAT slot RVAs; allocate new slots only for additional direct-branch imports.
- `NewIat`: Allocate a new IAT and patch direct branches only. Other references must be updated by the caller.
