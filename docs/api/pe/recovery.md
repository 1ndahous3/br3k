### ChangeKind

[Source](../../../lib/src/pe/image/editor.rs#L14)

Kind of operation recorded in an image editor's change history.

- `Headers`: Header sanitization, copying, or salvage.
- `Imports`: Normal import reconstruction or replacement.
- `DelayImports`: Delay-import restoration or replacement.
- `Resources`: Resource copying or merging.
- `Relocations`: Relocation-table construction or rebasing.
- `Tls`: TLS field sanitization.
- `Bytes`: Direct local byte edits.

#### build

```python
build(self, *, allow_partial: bool = ..., sanitize_headers: bool = ..., preserve_resources: bool = ..., discover_relocations: bool = ...) -> br3k.pe.BuildResult
```

Build only against the original capture. Partial output requires explicit opt-in.

Revalidates the current import model before applying independent resource, relocation, and sanitation policies. Complete means the selected checks succeeded, not that Windows can load or execute the reconstructed image. Raises ValueError for rejected partial output or an unsuccessful rebuild.

Parameters:

- `allow_partial`: False by default. Explicitly permit incomplete reconstruction and retain BuildStatus.Partial plus diagnostics in the returned result.
- `sanitize_headers`: Clear stale checksum, security, and bound-import fields. Defaults to True.
- `preserve_resources`: Restore absent resources from a matching reference. Does not merge conflicting resource trees. Defaults to True.
- `discover_relocations`: Infer a missing relocation table from pointer-shaped values. Defaults to False; inferred relocations make the resulting build partial.

### Strength

[Source](../../../lib/src/pe/recovery/imports.rs#L11)

Recovery preset controlling analysis effort and use of heuristic evidence. Explicit options may override preset fields.

- `Fast`: Use conservative address recovery without thunk tracing or code-reference recovery.
- `Auto`: Default: enable forwarders, thunk tracing, and bounded entry-point analysis while retaining exact address matching.
- `Aggressive`: Also allow nearest exports, single-entry and multiple IAT ranges, larger traces, and a full code scan.
