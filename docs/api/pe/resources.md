### ChangeKind

[Source](../../../lib/src/pe/diagnostics/resources.rs#L5)

Difference for one typed resource-tree path.

- `Added`: Leaf is present in the capture but absent from the reference.
- `Removed`: Leaf is present in the reference but absent from the capture.
- `Changed`: Leaf exists in both inputs with differing metadata or payload.

### MergePreference

[Source](../../../lib/src/pe/image.rs#L115)

Conflict policy when the same resource leaf exists in file and mapped sources.

- `File`: Prefer the file-source resource on conflict.
- `Mapped`: Prefer the mapped-source resource on conflict.
- `Larger`: Prefer the larger resource payload on conflict.
