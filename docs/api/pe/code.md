### ReferenceKind

[Source](../../../lib/src/pe/imports/types.rs#L226)

Recognized instruction-pattern family for an API reference. Recognition depends on the image architecture.

- `DirectCall`: Direct relative call to an API target.
- `DirectJump`: Direct relative jump to an API target.
- `ImmediateCall`: Call through a target materialized from an immediate value.
- `ImmediateJump`: Jump through a target materialized from an immediate value.
- `IndirectCall`: Indirect call through a pointer slot.
- `IndirectJump`: Indirect jump through a pointer slot.
