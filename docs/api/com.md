### IRundown

[Source](../../lib/src/vm/py_com_irundown.rs#L34)

A low-level COM IRundown callback context for an opened process.

Requires an initialized process-memory read strategy and build-matched COM symbol RVAs and layout offsets. Call `read_ipid_entries()` before `execute()`. The constructor only stores addresses; it does not validate symbol provenance.

#### __init__

```python
__init__(self, process: br3k.proc.Process, ole32_address: int, ole32_secret_rva: int, ole32_palloc_rva: int, ole32_emptyctx_rva: int, moxid_offset: int) -> None
```

Store the process, COM module base, symbol RVAs, and IPID-entry OXID field offset.

Parameters:

- `process`: Opened process with an initialized memory reader.
- `ole32_address`: Absolute target virtual address of the COM module containing these symbols.
- `ole32_secret_rva`: RVA of CProcessSecret::s_guidOle32Secret in the matching COM build.
- `ole32_palloc_rva`: RVA of the COM IPID allocator pointer in the matching module.
- `ole32_emptyctx_rva`: RVA of g_pMTAEmptyCtx in the matching module.
- `moxid_offset`: Byte offset of the OXID field within an IPID entry, from matching symbols.

#### read_ipid_entries

```python
read_ipid_entries(self) -> None
```

Read COM allocator/IPID entries from target memory and replace the cached entry list.

#### execute

```python
execute(self, ep: int, arg1: int = ...) -> bool
```

Try `IRundown::DoCallback` with target entry point `ep` and optional `arg1` (default zero).

Returns `True` on a successful callback and `False` if no entry succeeds. Requires previously read IPID entries and an initialized read context; connection, memory, and COM failures may raise `SystemError`.
