# br3k.proc

Generated by `cargo api` from Rust declarations and `///` documentation. Do not edit this file.

[API index](../api/index.md) | [Core guide](../core.md) | [PE workflows](../pe_recovery.md)

Process/thread lifecycle, memory strategies, snapshots, and thread-pool experiments.

Constructors configure wrappers; opening/creating and memory initialization are separate steps. Snapshot records are returned by query methods and generally have no public constructor. They are not live views of the target.

Example (requires an already running notepad.exe and sufficient access):
```python
from br3k import proc
process = proc.Process(name="notepad.exe",
    process_open_strategy=proc.ProcessOpenStrategy.OpenProcess,
    process_vm_read_strategy=proc.ProcessVmReadStrategy.ReadVirtualMemory)
process.open()
process.init_memory()
modules = process.modules()
regions = process.memory_map().executable
```

### Process

[Source](../../lib/src/vm/py_proc.rs#L524)

A process selection, native handle, and independent memory read/write strategies.

Select an existing process with `name`, decimal-string `pid`, or `current=True`; select a new one with `image_path` or an image `section_handle`. Selection precedence is current, PID, name, path, section. Construction does not open or create the process. Call `open()`, `create_user()`, or `create()` as appropriate, then `init_memory()` before strategy-based memory operations.

Strategies omitted from the constructor remain unset. Read and write choices are independent; read-only analysis need not configure writing. A supplied section handle is borrowed: keep its owning `Handle` alive through `create()`.

#### __init__

```python
__init__(self, *, current: bool = ..., name: str = ..., pid: str = ..., image_path: str = ..., section_handle: br3k.resource.Handle = ..., process_vm_read_strategy: br3k.proc.ProcessVmReadStrategy | int = ..., process_vm_write_strategy: br3k.proc.ProcessVmWriteStrategy | int = ..., process_open_strategy: br3k.proc.ProcessOpenStrategy | int = ..., thread_open_strategy: br3k.proc.ThreadOpenStrategy | int = ...) -> None
```

Select a target and store strategies without opening a handle.

`pid` must be a decimal string, not an integer. Missing selection, an invalid PID, a failed name lookup, or an unknown strategy value raises `ValueError`.

Parameters:

- `current`: Select the current process when True; takes precedence over other selectors.
- `name`: Existing executable basename to find, such as notepad.exe.
- `pid`: Existing process ID as a decimal string.
- `image_path`: Executable path for create_user(); does not start it during construction.
- `section_handle`: Image section for create(); keep this owning Handle alive until creation completes.
- `process_vm_read_strategy`: Read strategy; omitted means no reader until configured by a higher-level facade.
- `process_vm_write_strategy`: Write strategy; omitted means no writer.
- `process_open_strategy`: Required by open(); omitted means no open strategy.
- `thread_open_strategy`: Used by Thread.open(); omitted means no thread-open strategy.
