# br3k

br3k is a Windows research framework with an embedded Python runtime. Scripts combine process, memory, file, and PE operations through typed API objects and explicit strategies.

Use only for authorized, non-malicious education, research, and testing.

- [Core](core.md): native operations and configuration.
- [PE workflows](pe_recovery.md): capture, analysis, recovery, and editing.
- [Scripts](scripts.md): ready-to-edit scenarios and VM test suites.
- [Python API](development.md#documentation): build the reference for every registered namespace.
- [Development](development.md): stubs, type checking, hooks, packaging, and release tests.
