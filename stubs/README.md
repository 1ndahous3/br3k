# br3k Python Stubs

Type information and API docstrings for the Python module embedded in [br3k](https://github.com/1ndahous3/br3k). This package contains no executable implementation: run scenarios through br3k, not CPython.

Install the wheel in your editor/type checker's Python environment. Scripts continue to use `import br3k`; the installed `br3k-stubs` directory follows PEP 561.

The stubs are generated from Rust declarations with `cargo api`. Do not edit `.pyi` files by hand.

Use only for authorized, non-malicious education, research, and testing.
